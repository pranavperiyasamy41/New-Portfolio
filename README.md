# 🚀 Pranav Periyasamy's Portfolio

![Portfolio Header](./images/Home.png)

A sophisticated, highly interactive personal portfolio website showcasing my journey as a B-Tech Artificial Intelligence & Data Science student and Full Stack Developer.

## 🌟 Key Features

- **Modern UI/UX:** Dark-themed design with glassmorphism effects and smooth scrolling.
- **Interactive Animations:** Uses `IntersectionObserver` for scroll-triggered reveals and `circle-progress.js` for dynamic skill visualization.
- **Multi-Step Skill Section:** Categorized skills (Languages, Frontend, Backend, etc.) with a custom horizontal progress navigation.
- **Dynamic Projects Grid:** Animated project cards featuring GIF previews and direct links to live demos or source code.
- **Responsive Design:** Fully optimized for all screen sizes from mobile to desktop.
- **Custom Scroll Indicator:** A unique circular progress button that tracks scroll depth and provides a "return to top" function.
- **Contact Integration:** Built-in contact form powered by Formspree.

## 🛠️ Built With

- **Core:** HTML5, CSS3, JavaScript (Vanilla)
- **Frameworks/Libraries:** 
  - [jQuery](https://jquery.com/)
  - [Animate.css](https://animate.style/)
  - [Circle-Progress.js](https://github.com/kottenator/jquery-circle-progress)
  - [Font Awesome](https://fontawesome.com/)
- **Typography:** Josefin Sans
